راهنمای اجرای سریع در Termux (اندروید) و Linux

            
دستورات آماده برای راه‌اندازی کامل Noryka پس از استخراج فایل زیپ

          

          

            

              
۱. نصب خودکار پیش‌نیازها و بسته Noryka در Termux / Linux:

              unzip noryka-agent.zip && cd noryka && bash install-noryka-termux.sh
            

            

              
۲. اجرای هم‌زمان دروازه تلگرام، بله و زمان‌بند Cron در پس‌زمینه Termux:

              termux-wake-lock && noryka gateway run
            

            

              
۳. شروع چت و کدنویسی تعاملی در ترمینال یا اجرای همین وب‌اپ:

              noryka dashboard --port 8080 --skip-build   # یا: noryka webapp
